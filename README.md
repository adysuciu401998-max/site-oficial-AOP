Acțiune Ordine și Progres

INSTRUCTIUNI DE INSTALARE SI PUBLICARE

1. CONTINUTUL DOSARULUI

Creeaza un dosar numit site-oficial-AOP.

In interior trebuie sa existe:

index.html
sigla-aop.png
README.txt

IMPORTANT:
Imaginea siglei trebuie salvata cu numele exact:
sigla-aop.png

2. DESCHIDERE LOCALA

Deschide fisierul index.html cu Google Chrome,
Firefox sau Microsoft Edge.

Site-ul va functiona direct in browser.

3. PUBLICARE GRATUITA PE GITHUB PAGES

Pasul 1:
Acceseaza https://github.com/

Pasul 2:
Autentifica-te sau creeaza un cont gratuit.

Pasul 3:
Acceseaza:
https://github.com/new

Pasul 4:
Numele repository-ului:
site-oficial-AOP

Selecteaza Public.

Pasul 5:
Apasa Create repository.

Pasul 6:
Apasa Add file si apoi Upload files.

Incarca toate cele trei fisiere:
- index.html
- sigla-aop.png
- README.txt

Pasul 7:
Apasa Commit changes.

Pasul 8:
Acceseaza Settings -> Pages.

Pasul 9:
La Build and deployment selecteaza:
Deploy from a branch

Branch: main
Folder: / (root)

Apasa Save.

4. ADRESA SITE-ULUI

Dupa publicare, adresa va fi:

https://NUMELE-UTILIZATORULUI.github.io/site-oficial-AOP/

Inlocuieste NUMELE-UTILIZATORULUI cu numele
contului tau GitHub.

5. EDITAREA ULTERIOARA

Pentru modificarea site-ului:
- Intra in repository.
- Deschide index.html.
- Apasa Edit.
- Modifica informatiile.
- Apasa Commit changes.

6. INFORMATII CARE VOR FI COMPLETATE

- Numele presedintelui partidului.
- Componenta conducerii.
- Adresa oficiala.
- Telefonul.
- Adresa de e-mail.
- Comunicatele si noutatile.

7. DESIGN

Culori:
Bleumarin: #092e4b
Portocaliu: #f15b19
Alb: #ffffff
Gri deschis: #f3f6f8

Site-ul este adaptat pentru telefoane,
tablete si calculatoare.

Gazduirea GitHub Pages este gratuita pentru
repository-uri publice eligibile.
